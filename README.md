# 🌱 Projeto Front-End — ONG

Este projeto foi desenvolvido durante meus estudos na disciplina de **Desenvolvimento Front-End para Web**, no curso de **Engenharia de Software**.

O objetivo foi colocar em prática conceitos fundamentais do desenvolvimento web, criando uma página para uma ONG.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📄 Páginas do projeto

- Página inicial
- Página de projetos
- Página de cadastro

## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de arquivos e imagens
- Uso inicial de JavaScript
- Criação e organização de um projeto Front-End
